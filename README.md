# 食料物価ウォッチ（試作）

何の値上がりが、家計の食費をどれだけ押し上げているか。
総務省「消費者物価指数（CPI）」の食料241品目を、**上昇率ではなく寄与度**で並べる静的サイトです。

## いまできること（試作版）

- 食料・総合・生鮮食品を除く食料の前年同月比（最新月）
- 食料の前年同月比を中分類ごとの寄与度に分解（2026年1月分〜、月を切り替え可能）
- 品目ランキング（寄与度順／上昇率順の切り替え）と、±50%以上動いた品目の注意喚起
- 前年同月比の推移（2015年〜）
- 全品目の表（階層の開閉・検索）と、品目ごとの指数の推移

## データ

出典は `data/SOURCES.csv`。すべて `scripts/build_cpi.py` で再生成でき、実行のたびに公表値との検算を行います。
