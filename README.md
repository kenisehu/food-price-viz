# 食料物価ウォッチ（試作）

総務省「消費者物価指数（CPI）」の食料を、品目ごとに見られる静的サイトです。

**この版は、OpenGov.jp の CPI ページ（食料カテゴリ）の現在の構成をそのまま採用した「たたき台」です。**
改善（何をどう見せるか）は、このあとメンバーで議論して決めます。

## 構成（OpenGov.jp の CPI カテゴリ／品目ページに準拠）

トップのヘッダーから、別ページの「学校給食費の推移」にリンクしています。

- **食料トップ**（`#/`）：指数と前年同月比、上昇率・下落率1位、指数推移（5年／10年／20年／全期間＋任意期間、ナビゲーター）、
  サブカテゴリ表、上昇率・下落率上位10、全品目一覧（検索・サブカテゴリ絞り込み・並べ替え・開閉）、年次データ（各年1月）
- **サブカテゴリ**（`#/c/<分類コード>`）：上と同じ構成で、ランキングは上位5、サブカテゴリ表なし
- **品目**（`#/i/<品目コード>`）：指数と前年同月比、指数推移、年次データ、同じカテゴリの品目

## OpenGov.jp との違い（データの都合によるもの）

- 2025年基準（2026年7月分〜の公表基準）を使用。OpenGov.jp は2020年基準のまま
- 前年同月比は、小数第1位の指数から計算した値（小数第2位まで）。公表の前年同月比とは端数が合わないことがある
- 年次データに当年（1月分がある年）を含める

## データ

出典は `data/SOURCES.csv`。`python -X utf8 scripts/build_cpi.py` で `site/data/cpi_food.json` を再生成します。

## 学校給食費の推移（`site/school-lunch/`）

文部科学省「学校給食実施状況等調査」に基づく、全国平均の学校給食費（月額）を小学校・中学校別に表示するページです（`/school-lunch/`）。

### データ

- 対象: 公立の完全給食実施校
- 期間: 2006年度〜2025年度（公表値がある年度のみ）
- 全国平均: 都道府県別学校数による加重平均
- 欠損年度: 補完しません
- 平成27年度以前の小学校: 中学年の平均月額

公式ファイルは `data/raw/`、出典台帳は `data/SOURCES.csv`、表示用JSONは `site/data/school-lunch-fees.json` にあります。

### データ再生成

Python 3.12 と Poppler の `pdftotext` が必要です。Python側の外部パッケージは使用しません。

```bash
python -X utf8 scripts/build_school_lunch.py
```

スクリプトは公式PDFのSHA-256を確認し、表から数値を抽出してJSONを生成します。

参加ルールは [AGENTS.md](AGENTS.md) を参照してください。

本サイトは政府統計を加工して作成したもので、内容は国によって保証されたものではありません。
